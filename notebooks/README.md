# Colab workflow

`watervision_colab.ipynb` is a compact workflow scaffold for Colab installation, dataset directory checks, single-run training, and inference. It is not a copy of the complete source experiment notebook. The notebook's generic training cell does not reproduce the three-fold family-aware Experiment 02 evaluation; that requires the original family manifest and fold-specific configuration.

Dataset attribution and licensing appear in the notebook and in [`docs/dataset.md`](../docs/dataset.md) and [`docs/licensing.md`](../docs/licensing.md).
